Method: `benchmarks/isolated` (frozen home `tree_hash e4ef724880bda3618603d58922b35707`, unchanged after the run). Each U/UP trial ran in its own clone with its own daemon. Model `sonnet` (fixed), Claude Code 2.1.302, seed `p51`, 1 repetition, 47 tasks (`code.json` 27, `locate.json` 20) × 4 conditions = 188 runs, 0 errors. ZCIE version: the P4 build (before P5.2). Findings:
- The tool profile alone (`A0P`) halves the tokens but does not reduce the searches. The ZCIE context (`U`) reduces the searches and makes the answers correct (code 23/23 against 19/23). Both together (`UP`) give −72 % tokens on code questions.
- The edit tasks are the weak group: `U` costs more than `A0` (+15 %, interval includes 0, 4 pairs). The capsule gives signatures, and Claude Code reads the file before an edit anyway. P5.2 (source slices) addresses this.
- In the earlier, non-isolated measurements the baseline was the installed ZCIE (condition U), not a session with no ZCIE; the numbers above are therefore not comparable with AC-32 and AC-33 as written. AC-43 and AC-44 use this benchmark.
