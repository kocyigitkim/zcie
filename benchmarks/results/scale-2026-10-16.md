## 4. Findings

- All targets are met at 1M lines, with and without vector search.
- The vector search adds about 4 ms to an uncached search at 1M lines: the flat index reads all 274,351 int8 vectors of the workspace. An approximate index (the `VectorIndex` trait allows it) is the next step for more than about 5M lines.
- Capture p95 is about 20 ms at 1M lines against 4 ms at 100k lines (target 25 ms). The fsync time grows with the store; this is the value closest to its target.
- Run A has a higher p95 and p99 for some sub-millisecond operations (L0, symbol lookup) than run B. The cause was not found; with one run per configuration, treat differences below 1 ms as noise.

## 5. Limits

- Synthetic corpus with regular files; real repositories have longer files and more varied names.
- One run per configuration. The 5M-line corpus is not measured.
